# Bank-landing-2

Концепт лендинга Делового совета Россия–Индия, версия 4: тёмный фон с анимацией на canvas,
бирюзовые акценты, шрифт Open Sans.

- `site/index.html` — вся страница: разметка, стили и JS в одном файле, без сборки и зависимостей.

Локальный просмотр:

```bash
cd site && python3 -m http.server 8768
```

затем http://localhost:8768

GitHub Pages: https://smoil99.github.io/Bank-landing-2/ — публикует `.github/workflows/pages.yml`
при каждом пуше в `main` (Settings → Pages → Source = GitHub Actions).
